# -----------------------------------------------------------------------------
# Swath and scattered-point resampling
#
# pyresample is the PyTroll standard for satellite swath geometry, and it is
# what handles the INSAT grid after parallax correction: once cloud tops are
# shifted to their true ground positions the grid is no longer a regular sweep
# but an irregular scatter, which rasterio's affine warp cannot express.
#
# scipy.griddata would triangulate 888^2 points per frame, thirteen frames per
# window -- far too slow for an operational cadence. A hand-rolled KD-tree IDW
# is fast but smears convective cores, which are precisely the features this
# system exists to locate.
#
# pykdtree is pyresample's fast neighbour search backend and is pinned
# explicitly so the resampling path cannot silently fall back to the slower
# scipy tree.
pyresample==1.28.2
pykdtree==1.3.11
configobj==5.0.8

# -----------------------------------------------------------------------------

# -----------------------------------------------------------------------------
# RAG advisory — entirely local, no external API and no credential
#
# chromadb runs embedded with persistent storage; metadata filtering scopes
# NDMA guideline retrieval by hazard class, severity tier and region.
#
# sentence-transformers embeds queries and documents with e5-small-v2 on the
# CPU, so retrieval never contends for the VRAM the relay is holding. 384
# dimensions, about 130 MiB.
#
# outlines constrains the advisory model's logits to the CAPAlertInfo JSON
# schema during decoding, so the first sampled sequence is valid CAP content.
# There is no parse-and-retry loop and no stripping of markdown fences,
# because a token that would break the schema is never sampled.
#
# transformers is pinned explicitly rather than left to whichever of the two
# above resolves it first: they would otherwise be free to disagree, and the
# tokenizer is shared.
# -----------------------------------------------------------------------------
